# Постановка задачи

Для формирования динамических запросов используется библиотека Dynamic LINQ. Для демонстрации возможности работы добавлены фильтрация и сортировка товаров в каталоге (по категории, цене от и до, по названию и цене в обе стороны) и сортировка списка пользователей по любому столбцу.

# Dynamic LINQ

В приложение добавлена библиотека System.Linq.Dynamic.Core 1.7.4. В каталоге товаров условие Where собирается строкой из выбранных фильтров, значения передаются параметрами @0, @1 и объединяются через &&. Сортировка делается через OrderBy("Price desc"), строка для неё берётся только из словаря SortOptions. На странице «Пользователи» таблица сортируется кликом по заголовку столбца через OrderBy после ProjectTo<UserDto>, а фильтр по роли сделан динамическим Where с параметром. Запросы выполняются на стороне БД, в консоли видно SQL с WHERE и ORDER BY. 

# Mapper

В приложение добавлен AutoMapper 12.0.1, подключённый как сервис через AddAutoMapper в Program.cs. Настроен профиль AppMappingProfile, в котором есть правила ForMember и Ignore. При регистрации данные с формы приходят в RegisterDto и превращаются в User через _mapper.Map. Список пользователей на странице «Пользователи» (только для Admin) берётся из БД методом ProjectTo<UserDto>, поэтому хэш пароля в запрос не попадает.
